# MarketLens AI

Next.js app for AI-assisted stock analysis and market insights.

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm

## Local development

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command        | Description              |
| -------------- | ------------------------ |
| `npm run dev`  | Development server       |
| `npm run build` | Production build        |
| `npm run start` | Run production server   |
| `npm run lint`  | ESLint                   |
| `npm test`      | Vitest (unit tests)      |

## Stack

- **Next.js** (App Router)
- **TypeScript** & **React**
- **Tailwind CSS**
- **Radix UI**-based components (shadcn-style)

## Deploy

Build a production bundle with `npm run build`, then run `npm run start`, or deploy the Next.js app on any host that supports Node (for example [Vercel](https://vercel.com/docs/frameworks/nextjs)).
